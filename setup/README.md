## Setup

Open your Terminal application and navigate to your `~/code/ga/labs` directory:

```bash
cd ~/code/ga/labs
```

Navigate to [GitHub](https://github.com/) and create a new repository named **intro-to-javascript-objects-lab**.

- Make sure the repo is set to `public`
- You do not need a `README.md`
- You do not need a `.gitignore`

Using the `Quick Setup` option, clone your newly created repo into your `~/code/ga/labs` directory with the `git clone` command:

```bash
git clone https://github.com/<your-username>/intro-to-javascript-objects-lab.git
```

> Note: In the link above, where it says `<your-username>`, you should see the username from your GitHub account.

Next, `cd` into your new cloned directory, `intro-to-javascript-objects-lab`:

```bash
cd intro-to-javascript-objects-lab
```

Then, create an `app.js` file. This file will hold your work for this lab:

```bash
touch app.js
```

With the file created, open the contents of the directory in VS Code:

```bash
code .
```

Use `node` to execute the `app.js` file directly by using this command in your terminal:

```bash
node app.js
```
